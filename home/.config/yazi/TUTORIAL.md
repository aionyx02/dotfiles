## 30 秒最小集合

只記這九顆就能開始用，其他都是加分項：

| 鍵 | 意思 |
|---|---|
| `y` | 在 PowerShell 打這個字啟動（不是 `yazi`） |
| `j` `k` | 上下 |
| `h` | 回上層 |
| `l` | 進去 ／ 開檔 |
| `q` | 離開，**shell 會跟著跳到你所在的目錄** |
| `Q` | 離開，**shell 不跳** |
| `z` | 模糊搜尋跳轉（fzf） |
| `T` | 預覽窗放大 |
| `~` | 忘記按鍵時叫出完整說明 |

## 情境一：開工 — 從終端機進專案、改檔案、回到 shell

這是最常跑的一條路，先把它變成肌肉記憶。

```
y                    ← 在 PowerShell 打 y，不是 yazi
Z  myproject  Enter  ← zoxide 跳到專案（打片段就行）
f  config  Enter     ★ 過濾出 config 相關的檔案
l                    ★ 開啟 → Sublime 跳出來
（在 Sublime 改完存檔，切回終端機）
q                    ← 離開；shell 現在就站在那個目錄
npm run dev          ← 直接接著做事，不用再 cd
```

**為什麼用 `y` 不用 `yazi`**
`y` 是裝在你 PowerShell profile 裡的包裝函式。它用 `--cwd-file` 把 yazi 離開時的目錄寫到暫存檔，再讓 shell `cd` 過去。直接打 `yazi` 就沒有這個效果，離開後你還站在原地。

**`q` 和 `Q` 一定要分清楚**
- `q` = 離開**並帶走目錄** ← 逛完要接著在那裡做事
- `Q` = 離開**但不動 shell** ← 只是進去看一眼

進去確認一下某個檔案在不在、然後想回到原本工作目錄的時候，按 `Q`。

## 情境二：我知道檔名，但不知道它在哪

兩種打法，差別在你對位置的掌握程度。

### 完全不知道在哪 → `z`（fzf）

```
z                ← 叫出 fzf
tsconfig         ← 打片段，不用連續、不用完整
Enter            ← 直接跳過去
```

fzf 會遞迴掃當前目錄以下所有檔案，模糊比對。`tscfg` 也能命中 `tsconfig.json`。

### 大概知道在哪一層 → `f` 逐層縮 ★

```
l  src           ← 進 src
f  comp  Enter   ★ 過濾出含 comp 的項目
                 ← 若只剩 components/ 一個目錄，會自動進去並繼續過濾
f  butt          ★ 繼續縮，直到看到 Button.tsx
```

`f` 是這份設定裝的 **smart-filter**，比 yazi 原廠的過濾多了「唯一目錄自動進入」。在 `src/components/ui/forms/` 這種深層結構裡，這比 fzf 快，因為你**每一層都看得到還有什麼**，不會跳過頭。

### 要一份完整清單 → `s`（fd）

```
s                ← 叫出 fd 搜尋
*.test.ts        ← 支援萬用字元
Enter
```

`s` 會把**所有**符合的結果攤成一個虛擬目錄列表，可以在裡面上下看、多選、批次操作。`z` 只讓你跳到一個檔案。

> **選擇原則**：要**跳過去** → `z`；要**逐層確認** → `f`；要**一次看到全部符合的** → `s`。

按 `Ctrl+s` 取消搜尋狀態，回到原本的目錄。

## 情境三：我不知道檔名，只記得檔案裡寫過某句話

```
S                       ← 大寫 S，走 ripgrep 搜「內容」
DATABASE_URL            ← 要找的字串
Enter
                        ← 結果列表出現，j/k 上下看
Tab                     ← 想確認細節時開 spot 面板
l                       ★ 找到了就開啟
```

`s`（小寫）搜**檔名**，`S`（大寫）搜**內容**。這是 yazi 裡最容易記錯的一對。

## 情境四：回到我上禮拜常去的那個目錄

```
Z                ← 大寫 Z，zoxide
proj             ← 打片段
Enter
```

zoxide 記錄你**去過的頻率與時間**，打 `proj` 會優先跳到你最常去的那個 proj 開頭的目錄。跟 `z`（fzf 搜當前目錄以下的檔案）完全不同 —— `Z` 是跨整台機器的目錄歷史。

> 你 PowerShell profile 裡設了 `_ZO_EXCLUDE_DIRS`，排除了家目錄本身、AppData、OneDrive、Windows 目錄，所以 `Z` 的結果不會被雜訊淹沒。

## 情境五：在深層路徑裡穿梭

| 想做的事 | 按鍵 |
|---|---|
| 下一層 | `l` ★ |
| 上一層 | `h` |
| **回到剛才那個目錄** | `H` |
| 再往前 | `L` |
| 跳到清單最上 / 最下 | `gg` / `G` |
| 翻半頁 | `Ctrl+u` / `Ctrl+d` |
| 家目錄 | `gh` |
| 下載 | `gd` |

`h`/`l` 是**目錄層級**（上一層／下一層）；
`H`/`L` 是**瀏覽歷史**（上一頁／下一頁，像瀏覽器）。

在 A 目錄工作、跳去 B 拿個東西、想回 A —— 按 `H`，不是按一堆 `h`。

## 情境六：挑一批檔案搬到別的資料夾

```
Space Space Space    ← 逐個選（按一次會自動下移，可以連按）
                     ← 或用 v 進視覺模式再 j/k 刷一片
x                    ← 剪下（y 是複製）
h                    ← 退到上層
j j                  ← 移到目標資料夾上（不用進去！）
p                    ★ 貼上 → 直接進到那個資料夾裡
```

**這裡是 smart-paste 的價值**：原廠的 `p` 是貼到「你現在所在的目錄」，所以你得先 `l` 進去、貼上、再 `h` 退出。這份設定的 `p` 貼到**游標懸停的那個目錄**，省掉進出兩步。

如果游標停在一個**檔案**上（而不是目錄），`p` 就退回原本行為，貼到當前目錄。所以不會有意外。

| 相關鍵 | 動作 |
|---|---|
| `y` | 複製 |
| `x` | 剪下 |
| `p` ★ | 貼到游標所在目錄 |
| `P` | 貼上並覆蓋同名檔 |
| `Y` / `X` | 反悔，取消複製/剪下狀態 |
| `Ctrl+a` | 全選 |
| `Ctrl+r` | 反選 |
| `Esc` | 清除所有選取 |

## 情境七：下載了一堆檔名很醜的檔案，要批次改名

```
Ctrl+a               ← 全選（或用 Space 挑你要的那幾個）
r                    ← 改名
                     ← Sublime 跳出來，裡面是一份檔名清單，一行一個
```

在 Sublime 裡**像編輯文字檔一樣**改那份清單 —— 多游標、尋找取代、正規表示式，全部可用。**存檔並關閉視窗**後，yazi 會列出「舊名 → 新名」讓你確認，再套用。

這是 yazi 內建功能，不需要任何外掛。對「把 `IMG_20260801_*.jpg` 全部改成 `台北-01.jpg`」這種任務，比任何 GUI 改名工具都快。

**注意事項**

- **不要增減行數**。行數對不上 yazi 會拒絕執行。
- **一定要把 Sublime 視窗關掉**，yazi 才會繼續。批次改名走的是 `yazi.toml` 裡 `subl -w %s` 那條**阻塞式** opener（`-w` = wait），yazi 會一直等到視窗關閉為止。

> 冷知識：yazi 的批次改名原始碼是 `YAZI.opener.block(&r)` —— 它**只接受 `block = true` 的 opener**。所以 `yazi.toml` 裡 `edit` 一定要同時保留 `subl %s`（一般開檔用，非阻塞）和 `subl -w %s`（阻塞）兩條。只留非阻塞那條的話，按 `r` 會得到 `No text opener found`。改設定時別把那條刪了。

## 情境八：整理截圖／看圖

```
gd                   ← 跳到 Downloads
,m                   ← 依修改時間排序（最新的在前）
j j j                ← 往下滑，右邊預覽窗即時換圖
T                    ★ 看不清楚 → 預覽窗撐成全寬
T                    ★ 再按一次還原
d                    ← 不要的丟回收桶
```

**關於畫質**：這份設定把預覽調到 `1200x1600 / quality 90`（原廠是 `600x900 / 75`）。因為 WezTerm 走 kitty graphics protocol，顯示的是**真圖片**不是色塊近似，而你的 DPI 是 120，原廠解析度會被拉伸。

`image_filter` 刻意維持原廠的 `triangle` 沒改成 `lanczos3` —— 畫質提升主要來自解析度，`lanczos3` 只多換一點邊緣銳利度卻要付 3–5 倍濾波成本。

**快速刷過去不會卡**：預覽有 30ms 去抖動，連續按 `j` 時 yazi 不會為中途每張圖解碼，只有你停下來才觸發。

> ⚠️ **yazi 沒有縮圖牆／grid view**，這是 ranger 系 TUI 的共同限制。它永遠是「清單 + 單一預覽」。要看縮圖矩陣得用別的工具。

## 情境九：這部影片到底是什麼內容

```
j                    ← 游標移到影片上，預覽窗出現第一幀縮圖
Tab                  ← 開 spot 面板看 metadata
Tab                  ← 關掉
O                    ← 互動選單 → 選 start（用系統預設播放器開）
```

影片縮圖靠 `ffmpeg`／`ffprobe`。這兩個原本裝了但不在 PATH 上，已經在你 PowerShell profile 裡補上路徑解析（用萬用字元抓，所以 ffmpeg 升級後不會失效）。

## 情境十：壓縮檔裡面有什麼？要解壓

```
j                    ← 游標移到 .zip / .7z / .tar.gz 上
                     ← 預覽窗直接列出裡面的檔案清單，不用解開
Enter                ★ 確定要解 → 解壓到當前目錄
```

壓縮檔的預覽與解壓都是 yazi **內建**功能（`ya pub extract`），靠 `7z` 執行。`7-Zip` 原本也不在 PATH 上，已在 profile 補上。

支援 zip / 7z / tar / gz / xz / zstd / bz2 / rar / cab 等等。

## 情境十一：手滑刪錯了

```
gt                   ← 跳到回收桶
                     ← 這裡列出你刪過的檔案
Space                ← 選要救的
Enter                ← 還原
```

`d` 是丟到**回收桶**（可救），`D` 是**永久刪除**（救不回）。差一個 Shift，後果差很多。

`gt` 走的是 yazi 26.x 內建的 `trash://` 虛擬檔案系統，跟 Windows 資源回收筒是同一個地方 —— 你也可以直接開資源回收筒還原，效果一樣。

## 情境十二：下載資料夾爆了，要清

```
gd                   ← 跳到 Downloads
,S                   ← 依大小排序（大寫 S = 反向，大的在前）
                     ← yazi 會自動把檔案大小顯示出來
Space Space          ← 選中那幾隻肥的
d                    ← 丟回收桶
w                    ← 想看刪除進度就按 w（工作管理員）
```

排序鍵在按下時會**順手切換 linemode**，所以 `,S` 之後檔案大小會自動顯示在檔名右邊，不用另外按 `ms`。

排序全表（`,` 前綴，大寫 = 反向）：

| 鍵 | 依據 |
|---|---|
| `,a` | 字母 |
| `,n` | 自然排序（`file2` 在 `file10` 前面） |
| `,m` | 修改時間 |
| `,b` | 建立時間 |
| `,e` | 副檔名 |
| `,s` | 檔案大小 |
| `,r` | 隨機 |

## 情境十三：在 repo 裡看我改了哪些檔案

```
Z  myrepo  Enter     ← 跳到專案
                     ← 檔名旁邊自動出現 git 狀態符號
```

不需要按任何鍵。`git.yazi` 是**非同步 fetcher**：你進目錄的瞬間檔案列表就出現，git 狀態圖示稍後才浮上來。

所以在巨大的 repo 裡，最壞情況是「圖示慢半拍」，**不是「卡住」**。如果你看到圖示還沒出現，那是它還在跑，不是壞掉。

搭配 `f` 過濾可以很快聚焦到改動的檔案上。

## 情境十四：我要這個檔案的路徑，貼到別的地方

`c` 前綴，第二個鍵決定複製什麼：

| 鍵 | 複製到剪貼簿的內容 |
|---|---|
| `cc` | 完整路徑 `C:\Users\shawn\proj\src\index.ts` |
| `cd` | 所在目錄 `C:\Users\shawn\proj\src` |
| `cf` | 檔名 `index.ts` |
| `cn` | 不含副檔名 `index` |
| `cC` / `cD` | URL 形式 |

寫 import 路徑、貼進聊天室、丟給指令當參數，用這組最快。

## 情境十五：在兩個目錄之間搬東西

yazi 自己有分頁（跟 WezTerm 的分頁是兩回事）。

```
tt                   ← 在當前目錄開新分頁
Z  target  Enter     ← 第 2 個分頁跳到目標目錄
1                    ← 切回第 1 個分頁
Space Space          ← 選檔案
y                    ← 複製
2                    ← 切到第 2 個分頁
p                    ★ 貼上
```

| 鍵 | 動作 |
|---|---|
| `tt` | 開新分頁 |
| `tr` | 重新命名分頁 |
| `1`~`9` | 切到第 N 個分頁 |
| `[` / `]` | 上／下一個分頁 |
| `{` / `}` | 移動分頁位置 |
| `Ctrl+c` | 關閉分頁（只剩一個時等同離開） |

> 這些跟 WezTerm 熱鍵**不衝突** —— WezTerm 用的是 `Ctrl+1~9`、`Alt+[`、`Alt+]`，修飾鍵不同。
> 外面那一層怎麼分割、怎麼切，見文末〈附錄：WezTerm 這一層〉。

## 情境十六：對這個檔案跑一個指令

```
j                    ← 游標移到目標檔案
:                    ← 開指令列（會等指令跑完）
ffprobe %h           ← %h = 游標所在的檔案
Enter
```

| 鍵 | 差別 |
|---|---|
| `;` | 執行後**立刻**回到 yazi，適合背景任務 |
| `:` | **等指令跑完**並顯示輸出，適合要看結果 |

### 佔位符

⚠️ yazi 用的是 **`%` 開頭的佔位符**，不是 shell 原生的 `$0` / `$@`。這點跟多數人的直覺相反，也跟舊版 yazi 的教學不同。

| 佔位符 | 代表 |
|---|---|
| `%h` | 游標懸停的檔案（路徑） |
| `%s` | **所有選取**的檔案，空白分隔 |
| `%s1` `%s2` | 第 N 個選取的檔案 |
| `%d` | 選取檔案**所在目錄** |
| `%y` | 目前 yank（複製/剪下）中的檔案 |
| `%H` `%S` `%D` `%Y` | 同上，但取 URL 形式而非路徑 |
| `%%` | 跳脫，代表一個字面的 `%` |

多選之後用 `%s` 可以一次對一批檔案下手：

```
Space Space Space    ← 選三個 png
:                    ← 阻塞式指令列
magick %s -resize 50%% out.png
```

（注意結尾的 `50%%` —— 要傳一個字面的 `%` 給 ImageMagick 就得寫兩個。）

## 七個容易搞混的地方

### 1. `z` 和 `Z` 是反直覺的

- **`z` = fzf**（模糊搜尋當前目錄以下的**檔案**）
- **`Z` = zoxide**（跳到歷史常去的**目錄**）

小寫的是 fzf。很多人（包括寫這份文件的過程中）會記反。

### 2. `s` 和 `S`

- **`s` = 搜檔名**（fd）
- **`S` = 搜內容**（ripgrep）

### 3. `d` 和 `D`

- **`d` = 丟回收桶**（`gt` 可以救回來）
- **`D` = 永久刪除**（救不回來）

### 4. `j`/`k` 和 `J`/`K`

- **小寫 = 移動游標**（換檔案）
- **大寫 = 捲動預覽窗內容**（同一個檔案，看下面的內容）

長文件或長程式碼想往下看，是按 `J`，不是 `j`。

### 5. `h`/`l` 和 `H`/`L`

- **小寫 = 目錄層級**（上一層／下一層）
- **大寫 = 瀏覽歷史**（上一頁／下一頁）

### 6. `q` 和 `Q`

- **`q` = 離開並讓 shell cd 過去**
- **`Q` = 離開，shell 不動**

### 7. `f` 和 `/`

- **`f` ★ = 過濾**，把不符合的**藏起來**，清單變短
- **`/` = 尋找**，清單不變，只是**把游標跳到**符合的項目

## 附錄：WezTerm 這一層

yazi 跑在 WezTerm 裡面。這一節的鍵**全部由 WezTerm 攔下**，不會傳進 yazi —— 所以在 yazi 裡按也照樣有效，不用先離開。

### 分割螢幕

| 鍵 | 動作 |
|---|---|
| `Alt+Shift+\` | **左右**分割，新的 pane 在右邊 |
| `Alt+Shift+-` | **上下**分割，新的 pane 在下面 |

記符號的形狀就不會錯：`|` 是直線 → 中間切一條直的 → 左右並排；`-` 是橫線 → 上下並排。

新開的 pane 會**繼承目前的工作目錄**，不會跳回家目錄。

> 兩顆鍵各綁了兩次（`|` 和 `\`、`-` 和 `_`），因為有沒有按到 Shift 送出來的鍵名不一樣，兩個都收才不會有時靈有時不靈。
>
> 設定檔裡寫的是 `SplitHorizontal` / `SplitVertical`，但 WezTerm 的命名指的是**新 pane 往哪個方向長出去**，不是切線的方向 —— `SplitHorizontal` = 往水平方向長 = 左右並排。日後改設定時別被字面誤導。

### 分割之後

| 鍵 | 動作 |
|---|---|
| `Alt+h/j/k/l`（或 `Alt+方向鍵`） | 切到左／下／上／右的 pane |
| `Alt+Shift+h/j/k/l` | 往該方向調整大小，一次 4 格 |
| `Alt+z` | 目前 pane 暫時撐滿視窗／還原 |
| `Alt+w` | 關閉目前 pane |
| `Ctrl+Shift+空白` | 每個 pane 跳出一個大字母，按下去瞬移 |

⚠️ `Alt+w` 設的是 `confirm = false`，**按下去直接關，不會問你**，pane 裡還跑著東西也一樣。跟 yazi 的 `D` 一樣屬於「按錯就沒了」那一類。

`Alt+z` 和 yazi 的 `T` 是兩層不同的東西，可以疊著用：`Alt+z` 把 pane 撐滿視窗，再按 `T` 把預覽窗撐滿 pane —— 看圖的時候這組合最大。

### 分頁（WezTerm 的，不是 yazi 的）

| 鍵 | 動作 |
|---|---|
| `Ctrl+Shift+t` | 開新分頁 |
| `Ctrl+Shift+w` | 關閉分頁 |
| `Ctrl+1` ~ `Ctrl+8` | 跳到第 N 個 |
| `Ctrl+9` | 跳到**最後**一個 |
| `Alt+[` / `Alt+]` | 前／後一個 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 同上 |

### 典型用法：一邊 yazi、一邊做事

```
Alt+Shift+\          ← 左右切開
y                    ← 在右邊這個 pane 開 yazi
（逛、找檔案、開檔）
q                    ← 離開；這個 pane 的 shell 就站在那個目錄
Alt+h                ← 切回左邊繼續跑指令
```

比起「進 yazi → 出 yazi → 再進去」，分屏讓 yazi 常駐在旁邊當檔案總管用。

### 為什麼兩層不打架

yazi 用 `1`~`9`、`[`、`]`、`Ctrl+c` 管它自己的分頁，WezTerm 用 `Ctrl+1`~`9`、`Alt+[`、`Alt+]` —— 修飾鍵不同，各收各的。

`Ctrl+c` 是唯一一顆兩邊都想要的鍵。WezTerm 先攔：**有反白文字就複製，沒有就原封不動送進去**，所以在 yazi 裡按 `Ctrl+c` 關分頁照樣有效。

反過來，**`Alt` 開頭的鍵一律被 WezTerm 吃掉**。日後想在 yazi 綁新鍵，避開 Alt。

設定檔位置：`C:\Users\shawn\.config\wezterm\wezterm.lua`（分割與熱鍵在第 9 節）

## 附錄：這份設定改了什麼

只有 5 顆鍵被改過，其餘 100% 是 yazi 原廠預設 —— 所以**按 `~` 叫出的內建說明、以及網路上任何 yazi 教學，對你都完全適用**。

| 鍵 | 原本 | 改成 |
|---|---|---|
| `l` | `enter`（只進目錄） | `smart-enter`（目錄就進、檔案就開） |
| `Enter` | `open`（只開檔） | `smart-enter`（同上） |
| `f` | `filter --smart` | `smart-filter`（唯一目錄自動進入） |
| `p` | `paste`（貼到當前目錄） | `smart-paste`（貼到游標所在目錄） |
| `T` | 未使用 | `toggle-pane max-preview`（預覽全寬／還原） |

另外三項不需按鍵、背景生效：

- **git.yazi** — 檔案列表自動顯示 git 狀態
- **mime-ext** — 用副檔名判定檔案類型取代讀檔頭嗅探，**讓 yazi 變快**（Windows 沒有 `file(1)`，這是淨收益）
- **tokyo-night flavor** — 配色對齊 WezTerm，且主檔案區用 `bg = "reset"`，你的 90% 毛玻璃完整保留

設定檔位置：`C:\Users\shawn\AppData\Roaming\yazi\config\`

```
yazi.toml     預覽品質、Sublime opener、外掛 fetcher 註冊
keymap.toml   上面那 5 顆鍵
theme.toml    flavor
init.lua      git.yazi 初始化
package.toml  ya pkg 的鎖定檔（記錄外掛版本，勿手改）
```

外掛升級：`ya pkg upgrade`
移除某個外掛：`ya pkg remove yazi-rs/plugins:git`
